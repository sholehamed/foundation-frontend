# Frontend milestones

| Milestone | Deliverable |
| --- | --- |
| F00 | Standalone Angular 22 shell, lazy routes, API connectivity, unit tests, CI |
| F01 | Runtime config, API client, error mapping, tenant-aware session integration |
| F02 | Auth routes, permission guards/directives, navigation that reflects backend access |
| F03 | Layouts, Material design tokens, RTL/LTR, locale and dark/light themes |
| F04 | Shared reusable forms, tables, selectors and async states |
| F05 | Frontend observability: client diagnostics, trace correlation, privacy policy |
| F06 | Fully tested business vertical slice against backend API |

Backend is the security authority. Protected routes fail closed until a real authentication solution exists. Introduce capabilities via focused, tested PRs.
